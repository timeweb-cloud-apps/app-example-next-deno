# next on deno

Пример next на deno для Timeweb Cloud Apps.

## Параметры деплоя

| Параметр | Значение |
| --- | --- |
| Runtime | `deno` |
| Фреймворк в API | `next.js` |
| Тип приложения | `frontend` |
| Команда сборки | `deno task build` |
| Директория сборки | `out` |

## Локальный запуск

```bash
deno install --allow-scripts
deno task build
```
